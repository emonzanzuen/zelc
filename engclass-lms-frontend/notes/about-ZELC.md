# ZELC — Zanzuen English Learning Center

## 1. Identitas Brand

**ZELC** merupakan singkatan dari **Zanzuen English Learning Center**, yaitu platform pembelajaran Bahasa Inggris yang menyediakan berbagai materi, kursus, latihan, kuis, dan pembelajaran terstruktur secara online.

### Arti Nama

* **ZE** → Zanzuen English
* **LC** → Learning Center
* **Zanzuen** → identitas utama brand
* **English** → fokus utama pembelajaran
* **Learning Center** → pusat pembelajaran Bahasa Inggris

### Tagline

**Learn English, Grow Beyond.**

### Kesan Brand

ZELC memiliki kesan **profesional, edukatif, modern, dan fleksibel**, sehingga dapat dikembangkan sebagai platform **LMS pembelajaran Bahasa Inggris berbayar**.

---

# 2. Konsep Warna Logo

Logo ZELC menggunakan **ungu sebagai warna identitas utama brand**, dengan warna pendamping yang menyesuaikan tampilan **Light Mode** dan **Dark Mode** website.

## Palet Warna

| Warna              | Hex       | Fungsi                                 |
| ------------------ | --------- | -------------------------------------- |
| **Primary Purple** | `#7C3AED` | Warna utama identitas ZELC             |
| **Deep Purple**    | `#6D28D9` | Warna ungu lebih gelap untuk aksen     |
| **White**          | `#FFFFFF` | Background Light Mode / teks Dark Mode |
| **Dark**           | `#111827` | Teks dan elemen pada Light Mode        |

### Light Mode

**Logo:** Purple + Dark

* Maskot menggunakan elemen warna ungu.
* Detail penting pada maskot menggunakan ungu.
* Tulisan **ZELC** menggunakan warna Dark.
* Background website menggunakan putih.

**Kesan:** bersih, modern, profesional, dan edukatif.

### Dark Mode

**Logo:** Purple + White

* Maskot tetap menggunakan elemen warna ungu.
* Detail penting tetap mempertahankan warna ungu.
* Tulisan **ZELC** berubah menjadi putih.
* Background website menggunakan warna gelap.

**Kesan:** modern, elegan, dan tetap nyaman dilihat.

---

# 3. Konsep Maskot

Maskot utama ZELC berupa **karakter pelajar laki-laki** yang merepresentasikan pengguna dan aktivitas pembelajaran Bahasa Inggris.

### Karakteristik Maskot

* Menggunakan **headset** sebagai simbol *listening & speaking*.
* Menggunakan **buku atau tablet** sebagai simbol *learning*.
* Memiliki ekspresi yang **ramah dan percaya diri**.
* Menggunakan gaya ilustrasi **flat mascot**.
* Tidak terlalu kekanak-kanakan.
* Menggunakan elemen **ungu sebagai identitas utama**.
* Dapat digunakan kembali pada berbagai bagian dan media ZELC.

### Penggunaan Maskot

Maskot dapat digunakan pada:

* Website utama
* Course page
* Empty state
* Loading screen
* Halaman pembelajaran
* Sertifikat
* Materi promosi
* Media sosial
* Ilustrasi fitur tertentu

---

# 4. Sistem Logo

Tidak perlu membuat desain logo yang berbeda untuk setiap mode. Gunakan **satu desain logo** dengan dua varian warna yang menyesuaikan tampilan website.

```text
ZELC Logo
├── Light Variant
│   └── Purple + Dark
│
└── Dark Variant
    └── Purple + White
```

### Prinsip Utama

> 🟣 **Ungu = identitas utama ZELC**
> ⚫ **Dark = pasangan untuk Light Mode**
> ⚪ **White = pasangan untuk Dark Mode**

Dengan konsep ini, logo ZELC tetap memiliki **identitas visual yang kuat, konsisten, dan mudah dikenali** baik pada Light Mode maupun Dark Mode.

Konsep tersebut juga memungkinkan logo digunakan secara fleksibel pada website, aplikasi, sertifikat, materi promosi, favicon, dan berbagai media branding ZELC.
